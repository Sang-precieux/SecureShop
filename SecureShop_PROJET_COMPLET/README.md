# SecureShop — Boutique + OTP 40 s + Administration

**Projet Django complet et indépendant.** Voir **LISEZ_MOI_D_ABORD.md**.

Sur Windows :
1. `INSTALLER_WINDOWS.bat` (installe Django et crée la base SQLite).
2. `DEMARRER_WINDOWS.bat` (démarre la boutique sur http://127.0.0.1:8000/).
3. `CREER_ADMIN_WINDOWS.bat` (crée le compte administrateur).

Les paiements sont **fictifs**. Les secrets privés sont générés localement dans `.env`.
